## 🧑‍💼 About Me

I'm a **certified Power BI Developer** with **4.2 years** of experience building automated dashboards, data models and SQL-based reporting for enterprise banking. At **HCLTech** I'm a **BI Engineer** on **Allied Irish Banks (AIB)**, where I deliver fraud and financial-crime analytics. I'm also a **Claude Certified Architect (Professional)**, bringing AI agents and LLM workflows into BI.

- 🏦 **Now:** BI Engineer at HCLTech (Jan 2024 – present), building AIB's Fraud Analytics & Reporting platform and FinCrime ODD / STR dashboards
- 📉 **Impact:** **80%** less manual Excel work, **85%** less manual data extraction, and fraud reporting effort cut from **15 FTE to 2**
- 🧩 **Strengths:** star-schema semantic models, advanced DAX, Power Query, T-SQL, RLS / OLS, incremental refresh, DEV → TEST → PROD pipelines
- 🤖 **AI:** Claude API, Claude Code and MCP; Gemini & Agent Development Kit on Google Cloud; AWS AI
- 🏆 **Community:** regular participant in **ZoomCharts Data Challenges**
- 💼 **Open to:** Senior Data Analyst · BI Developer · Power BI Developer roles
